# Domain Docs

Guidelines on how the CKA Wissensnetz and technical notes are structured.

## Before Exploring or Teaching, Read These

- **`CONTEXT.md`** at root: Core Kubernetes glossary and analogies.
- **`MISSION.md`** at root: Exam timeline, daily schedule, target score.
- **`RESOURCES.md`** at root: Reference links and tool inventory.
- **`learning-records/`**: Chronological records of completed concepts.

# CKA Learning & Triage Labels

This repository uses custom labels tailored to active CKA exam preparation
and Birkenbihl learning dynamics.

## Status

| Label | Meaning |
| :--- | :--- |
| `status:backlog` | Topic / lab not yet started |
| `status:in-progress` | Actively learning & practicing |
| `status:repetition-due` | Spaced repetition due for long-term retention |
| `status:mastered` | Concept & speed drill successfully mastered |

## Lernberg Level

| Label | Meaning |
| :--- | :--- |
| `lernberg:tal` | Conceptual introduction, KaWa, mental model |
| `lernberg:hang` | Guided hands-on terminal tasks & standard YAMLs |
| `lernberg:gipfel` | Timed exam drills & complex troubleshooting |

## Task Type

| Label | Meaning |
| :--- | :--- |
| `type:concept-kawa` | Birkenbihl KaWa & Wissensnetz anchoring |
| `type:hands-on-lab` | Terminal & manifest implementation |
| `type:troubleshooting` | Broken cluster / pod diagnosis |
| `type:speed-drill` | Fast command-line fluency & kubectl generators |
